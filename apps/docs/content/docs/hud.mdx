The `hud` theme turns every component into a sci-fi control panel: deep navy surfaces, cyan light, sharp corners and a soft glow on buttons, badges, cards, toggles and progress bars.

<HudShowcase />

## Turn it on

```html
<html data-theme="hud">
```

Or only for one section:

```html
<section data-theme="hud">...</section>
```

Nothing else changes in your code. The hud theme switches on the [`holo` interaction mode](/docs/interaction-engine), so components glow and get their futuristic behaviour automatically. Set `data-orbit-mode="standard"` to keep the colors but calm the behaviour.

## HUD effects

These classes add the details. They use the theme's `primary` color, so they work in every theme and look best in `hud`.

| Class | What it does |
| --- | --- |
| `hud-frame` | Corner brackets, like a targeting frame |
| `hud-scan` | A light line that sweeps from top to bottom |
| `hud-grid` | Blueprint style grid background |
| `hud-glow` | Glowing outline in the primary color |
| `text-glow` | Glowing text in the current text color |
| `clip-corner` | Cut corners (top left and bottom right) |

### Fine tuning

| Variable | Default | Used by |
| --- | --- | --- |
| `--frame-c` | primary color | `hud-frame` bracket color |
| `--frame-s` | `14px` | `hud-frame` bracket length |
| `--frame-w` | `2px` | `hud-frame` bracket thickness |
| `--scan-speed` | `3.5s` | `hud-scan` sweep duration |
| `--grid-size` | `24px` | `hud-grid` cell size |
| `--clip` | `10px` | `clip-corner` cut size |
| `--orbit-glow` | `0` (`0.6` in holo) | Glow strength of all components |

```html
<div class="card hud-frame [--frame-s:24px] [--frame-c:var(--color-secondary)]">...</div>
```

## Holo behaviour in any theme

Want the futuristic behaviour without the hud colors? Use the mode on its own:

```html
<html data-theme="dark" data-orbit-mode="holo">
```

Or only the glow:

```css
[data-theme="dark"] {
  --orbit-glow: 0.6;
}
```
