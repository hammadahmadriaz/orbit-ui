<Preview align="stack">
  <Field label="Email" hint="We will never share your email.">
    <Input type="email" placeholder="you@example.com" />
  </Field>
</Preview>

<Tabs items={["React", "HTML"]}>
<Tab value="React">

```tsx
import { Field, Input } from "orbitui/react";

<Field label="Email" hint="We will never share your email.">
  <Input type="email" placeholder="you@example.com" />
</Field>
```

`Field` creates the ids and connects the label, hint and error to the input with `aria-describedby` and `aria-invalid`.

</Tab>
<Tab value="HTML">

```html
<div class="field">
  <label class="field-label" for="email">Email</label>
  <input id="email" type="email" class="input" placeholder="you@example.com" aria-describedby="email-hint" />
  <p id="email-hint" class="field-hint">We will never share your email.</p>
</div>
```

</Tab>
</Tabs>

## Textarea and Select

<Preview align="stack">
  <Field label="Country">
    <Select defaultValue="at">
      <option value="at">Austria</option>
      <option value="de">Germany</option>
      <option value="pk">Pakistan</option>
    </Select>
  </Field>
  <Field label="Message">
    <Textarea placeholder="Write something..." />
  </Field>
</Preview>

<Tabs items={["React", "HTML"]}>
<Tab value="React">

```tsx
import { Field, Select, Textarea } from "orbitui/react";

<Field label="Country">
  <Select defaultValue="at">
    <option value="at">Austria</option>
    <option value="de">Germany</option>
  </Select>
</Field>
<Field label="Message">
  <Textarea placeholder="Write something..." />
</Field>
```

</Tab>
<Tab value="HTML">

```html
<select class="select">
  <option>Austria</option>
  <option>Germany</option>
</select>
<textarea class="textarea" placeholder="Write something..."></textarea>
```

</Tab>
</Tabs>

## Classes

| Class | Description |
| --- | --- |
| `input` `textarea` `select` | Controls |
| `input-primary` ... `input-error` | Color (works on all three) |
| `input-sm` `input-md` `input-lg` | Size |
| `input-ghost` | Borderless style |
| `field` `field-label` `field-hint` `field-error` | Field layout |
