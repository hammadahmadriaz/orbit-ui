```tsx
"use client";

import { useState } from "react";
import {
  Button,
  Modal,
  ModalActions,
  ModalBody,
  ModalDescription,
  ModalHeader,
  ModalTitle,
} from "@orbitdesign/ui/react";

export function DeleteProject() {
  const [open, setOpen] = useState(false);

  return (
    <>
      <Button color="primary" onClick={() => setOpen(true)}>Open modal</Button>

      <Modal open={open} onClose={() => setOpen(false)}>
        <ModalHeader>
          <ModalTitle>Delete project?</ModalTitle>
          <ModalDescription>This removes the project and all of its files.</ModalDescription>
        </ModalHeader>
        <ModalBody>You can restore it from the trash for 30 days.</ModalBody>
        <ModalActions>
          <Button variant="ghost" onClick={() => setOpen(false)}>Cancel</Button>
          <Button color="error" onClick={() => setOpen(false)}>Delete</Button>
        </ModalActions>
      </Modal>
    </>
  );
}
```

A `<form method="dialog">` closes the dialog when any of its buttons is clicked, with no JavaScript.

## Interaction modes

Open the modal in each mode.

<ModeCompare>
  <ModalDemo />
</ModeCompare>

- **Standard**: a short fade and slide.
- **Enhanced**: the same with smoother easing.
- **Holo**: a system window. It appears as a point, stretches into a line of light, then opens to full height. A single scan passes over the content, a light line runs along the top edge, and the page behind gets a vignette and a faint grid. Closing plays the same steps in reverse.

```tsx
<Modal open={open} onClose={close} mode="holo">...</Modal>
<Modal open={open} onClose={close} mode="holo" effects={{ scan: false }}>No scan</Modal>
```

The React `Modal` waits for the exit animation before it closes the dialog, so closing is animated in every browser. With plain HTML, opening is animated and closing is instant.

## What the browser handles for you

Because the modal is a real `<dialog>` opened with `showModal()`:

- Focus moves into the modal and is trapped there
- <kbd>Esc</kbd> closes it (the React component calls `onClose`)
- It renders in the top layer, so no z-index problems
- Focus goes back to the trigger when it closes

Orbit UI adds **scroll lock**: the page behind cannot scroll while the modal is open, without the layout jumping when the scrollbar disappears. Nested modals keep the lock until the last one closes. Turn it off with `lockScroll={false}`.

## Accessibility

- Uses `<dialog>` with `showModal()`: the rest of the page becomes inert, focus is trapped and returns to the trigger.
- Give the modal a `ModalTitle` so it has an accessible name.
- Escape closes the modal, unless a tooltip inside is open: then Escape closes the tooltip first.
- All open and close animations are skipped when the user prefers reduced motion.
