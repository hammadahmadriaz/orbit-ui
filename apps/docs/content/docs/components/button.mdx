## Loading and disabled

<Preview>
  <LoadingButtonDemo />
  <Button loading>Loading</Button>
  <Button disabled>Disabled</Button>
</Preview>

```tsx
<Button loading>Loading</Button>
<Button disabled>Disabled</Button>
```

`loading` disables the button, shows a spinner and sets `aria-busy`.

## As a link

```tsx
import Link from "next/link";

<Button asChild color="primary">
  <Link href="/signup">Sign up</Link>
</Button>
```

  type={{

Also accepts every native `<button>` attribute.

## Classes

| Class | Description |
| --- | --- |
| `btn` | Base class |
| `btn-primary` ... `btn-error` | Color |
| `btn-outline` `btn-soft` `btn-ghost` `btn-link` | Variant |
| `btn-xs` `btn-sm` `btn-md` `btn-lg` `btn-xl` | Size |
| `btn-square` `btn-circle` | Equal width and height |
| `btn-block` `btn-wide` | Width |

## CSS variables

| Variable | Default | Description |
| --- | --- | --- |
| `--btn-h` | `2.5rem` | Height |
| `--btn-px` | `1rem` | Horizontal padding |
| `--btn-fs` | `0.875rem` | Font size |
| `--btn-color` | none | Main color, set by color classes |
| `--btn-fg` | none | Text color on solid buttons |
