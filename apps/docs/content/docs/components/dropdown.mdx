```tsx
import {
  Dropdown,
  DropdownItem,
  DropdownLabel,
  DropdownMenu,
  DropdownSeparator,
  DropdownTrigger,
} from "@orbitdesign/ui/react";

<Dropdown>
  <DropdownTrigger variant="outline">Options</DropdownTrigger>
  <DropdownMenu>
    <DropdownLabel>Project</DropdownLabel>
    <DropdownItem onSelect={() => edit()}>Edit</DropdownItem>
    <DropdownItem>Duplicate</DropdownItem>
    <DropdownItem>Share</DropdownItem>
    <DropdownSeparator />
    <DropdownItem danger>Delete</DropdownItem>
  </DropdownMenu>
</Dropdown>
```

Closes on outside click, <kbd>Esc</kbd> and after choosing an item. Arrow keys move between items.

<Tab value="HTML">

No JavaScript needed, it uses `<details>`:

```html
<details class="dropdown">
  <summary class="btn btn-outline">Options</summary>
  <ul class="dropdown-content menu">
    <li class="menu-label">Project</li>
    <li><a class="menu-item" href="/edit">Edit</a></li>
    <li><button class="menu-item">Duplicate</button></li>
    <li class="menu-divider"></li>
    <li><button class="menu-item menu-item-danger">Delete</button></li>
  </ul>
</details>
```

## Interaction modes

<ModeCompare>

      <DropdownItem shortcut="Ctrl+D">Duplicate</DropdownItem>
      <DropdownSeparator />
      <DropdownItem danger>Delete</DropdownItem>
    </DropdownMenu>
  </Dropdown>
</ModeCompare>

- **Standard and enhanced**: the menu fades and slides in, and fades out when it closes.
- **Holo**: the menu unfolds from the edge of the trigger like a targeting list. The highlighted row gets a glowing bracket on its left edge and a light sweep across it.

```tsx
<Dropdown mode="holo">...</Dropdown>
```

## Shortcuts and typeahead

Show a shortcut hint with `shortcut`. It is visual only, so wire the real keyboard shortcut in your app.

```tsx
<DropdownItem shortcut="Ctrl+E" onSelect={edit}>Edit</DropdownItem>
```

While the menu is open, type the first letters of an item to jump to it. Pressing the same letter again moves to the next item that starts with it.

## Classes

| `menu` | Vertical list |
| `menu-item` | Clickable row |
| `menu-item-danger` | Destructive row |
| `menu-label` | Small heading |

| `menu-shortcut` | Shortcut hint |

## Accessibility

- The trigger has `aria-haspopup="menu"`, `aria-expanded` and `aria-controls`.
- Opening moves focus to the first item. Arrow keys, Home, End and typeahead move between items. Escape closes and returns focus to the trigger. Tab closes the menu.
- Items are `role="menuitem"` buttons, so Enter and Space choose them.
