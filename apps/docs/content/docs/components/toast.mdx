## Setup

Wrap your app once with `ToastProvider`:

```tsx title="app/layout.tsx"
import { ToastProvider } from "@orbitdesign/ui/react";

export default function RootLayout({ children }) {
  return (
    <html lang="en">
      <body>
        <ToastProvider position="bottom-end">{children}</ToastProvider>
      </body>
    </html>
  );
}
```

## Usage

Call `toast()` from any component:

```tsx
"use client";

import { Button, useToast } from "@orbitdesign/ui/react";

export function SaveButton() {
  const { toast } = useToast();

  return (
    <Button
      color="primary"
      onClick={() =>
        toast({
          status: "success",
          title: "Changes saved",
          description: "Your profile has been updated.",
        })
      }
    >
      Save
    </Button>
  );
}
```

`toast()` returns an id. Close one with `dismiss(id)`, or all with `dismiss()`.

### With an action

```tsx
toast({
  title: "File deleted",
  duration: 8000,
  action: <Button size="xs" variant="outline" onClick={undo}>Undo</Button>,
});
```

## HTML

The CSS works without React. Position a `toast` container and put alerts inside:

```html
<div class="toast toast-top-end" role="region" aria-label="Notifications">
  <div class="alert alert-success toast-item" role="status">
    <div class="alert-title">Changes saved</div>
    <div class="alert-description">Your profile has been updated.</div>
  </div>
</div>
```

## Classes

| Class | Description |
| --- | --- |
| `toast` | Fixed container |
| `toast-top-start` ... `toast-bottom-end` | Position |
| `toast-item` | One notification (combine with `alert`) |
| `toast-close` | Close button position |
