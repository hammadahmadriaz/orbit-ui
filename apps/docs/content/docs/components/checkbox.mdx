## Props

### Checkbox

<TypeTable
  type={{
    color: { type: '"primary" | "secondary" | "accent" | "success" | "warning" | "error"', default: '"primary"' },
    size: { type: '"sm" | "md" | "lg"', default: '"md"' },

### Toggle

<TypeTable
  type={{
    color: { type: '"primary" | "secondary" | "accent" | "success" | "warning" | "error"', default: '"primary"' },
    size: { type: '"sm" | "md" | "lg"', default: '"md"' },
  }}

Both accept every native `<input>` attribute such as `checked`, `onChange`, `name` and `disabled`.

## Classes

| Class | Description |
| --- | --- |
| `checkbox` `toggle` | Base classes |
| `checkbox-primary` ... `checkbox-error` | Checkbox color |
| `toggle-primary` ... `toggle-error` | Toggle color |
| `checkbox-sm` `checkbox-lg` `toggle-sm` `toggle-lg` | Size |
