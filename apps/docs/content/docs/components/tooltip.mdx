import { Button, Tooltip } from "@orbitdesign/ui/react";

<Tooltip content="Top (default)">
  <Button>Top</Button>

  <Button>Bottom</Button>
</Tooltip>

The trigger gets `aria-describedby`, so screen readers read the tooltip text.

<Tab value="HTML">

Short version with `data-tip`:

```html
<span class="tooltip" data-tip="Top (default)">
  <button class="btn">Top</button>
</span>
<span class="tooltip tooltip-bottom" data-tip="Shown below">
  <button class="btn">Bottom</button>
</span>
```

Or with rich content:

```html
<span class="tooltip">
  <button class="btn" aria-describedby="tip-1">Shortcut</button>
  <span id="tip-1" role="tooltip" class="tooltip-content">Press <kbd>Ctrl</kbd> + <kbd>K</kbd></span>
</span>
```

## Interaction modes

Hover or Tab to each button.

<ModeCompare>
  <Tooltip content="Target acquired"><Button variant="outline">Scan</Button></Tooltip>
</ModeCompare>

- **Standard and enhanced**: fades and slides in.
- **Holo**: a readout. The text is revealed from left to right in steps, like a system typing it, inside a thin accent frame.

## Delay

```tsx
<Tooltip content="Appears after half a second" delay={500}>...</Tooltip>
```

```html
<span class="tooltip [--tt-delay:500ms]" data-tip="Appears after half a second">...</span>
```

## Classes

| Class | Description |
| --- | --- |
| `tooltip` | Wrapper. Use `data-tip` for simple text |
| `tooltip-content` | Rich content element |
| `tooltip-top` `tooltip-bottom` `tooltip-left` `tooltip-right` | Position |
| `tooltip-primary` ... `tooltip-error` | Color |
| `tooltip-open` | Always visible |

## CSS variables

| Variable | Default | Description |
| --- | --- | --- |
| `--tt-delay` | `120ms` | Delay before showing |

## Accessibility

- Shows on hover and on keyboard focus. The trigger gets `aria-describedby`, so screen readers read the text.
- **Escape** hides the tooltip, whether it was opened by hover or focus (WCAG 1.4.13). It stays hidden until the pointer leaves and focus moves away. Escape is not passed on, so a surrounding modal stays open.
- Keep tooltip text short and do not put interactive content inside.
