## Radial gauge

A circular gauge in HUD style. It animates smoothly when the value changes.

<Preview>
  <RadialProgressDemo />
</Preview>

<Tabs items={["React", "HTML"]}>
<Tab value="React">

```tsx
import { RadialProgress } from "@orbitdesign/ui/react";

<RadialProgress value={72} />
<RadialProgress value={45} color="secondary" size="6rem" thickness="6px" />
<RadialProgress value={90} color="success">OK</RadialProgress>
```

</Tab>
<Tab value="HTML">

```html
<div class="progress-radial" style="--value: 72" role="progressbar" aria-valuenow="72">72%</div>
<div class="progress-radial progress-secondary" style="--value: 45; --size: 6rem; --thickness: 6px">45%</div>
```

</Tab>
</Tabs>

## Props

### Progress

<TypeTable
  type={{

    size: { type: '"xs" | "sm" | "md" | "lg"', default: '"md"' },
    striped: { type: "boolean", description: "Animated stripes." },

### RadialProgress

<TypeTable
  type={{

## Classes

| Class | Description |
| --- | --- |
| `progress` | Bar, on a `<progress>` element |
| `progress-striped` | Animated stripes |
| `progress-radial` | Circular gauge, set `--value` |
| `progress-primary` ... `progress-error` | Color |
| `progress-xs` `progress-sm` `progress-md` `progress-lg` | Bar height |
