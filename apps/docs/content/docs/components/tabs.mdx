<Tabs items={["React", "HTML"]}>
<Tab value="React">

```tsx
import { Tab, TabList, TabPanel, Tabs } from "@orbitdesign/ui/react";

<Tabs defaultValue="overview">
  <TabList aria-label="Project">
    <Tab value="overview">Overview</Tab>
    <Tab value="activity">Activity</Tab>
    <Tab value="settings">Settings</Tab>
  </TabList>
  <TabPanel value="overview">...</TabPanel>
  <TabPanel value="activity">...</TabPanel>
  <TabPanel value="settings">...</TabPanel>
</Tabs>
```

Use the arrow keys, Home and End to move between tabs.

</Tab>
<Tab value="HTML">

```html
<div role="tablist" class="tabs tabs-line">
  <button role="tab" class="tab" aria-selected="true">Overview</button>
  <button role="tab" class="tab">Activity</button>
  <button role="tab" class="tab">Settings</button>
</div>
<div role="tabpanel" class="tab-panel">...</div>
```

With plain HTML you switch tabs yourself by moving `aria-selected="true"` (or the `tab-active` class).

</Tab>
</Tabs>

## Controlled

```tsx
const [tab, setTab] = useState("overview");

<Tabs value={tab} onValueChange={setTab}>...</Tabs>
```

## Classes

| Class | Description |
| --- | --- |
| `tabs` | Container (the tab list) |
| `tab` | One tab |
| `tab-active` | Active tab (or use `aria-selected="true"`) |
| `tab-panel` | Panel content |
| `tabs-line` `tabs-boxed` `tabs-pill` | Variant |
| `tabs-primary` `tabs-secondary` `tabs-accent` `tabs-neutral` | Color |
| `tabs-sm` `tabs-md` `tabs-lg` | Size |
