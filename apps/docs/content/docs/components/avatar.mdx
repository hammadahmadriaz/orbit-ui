<Tabs items={["React", "HTML"]}>
<Tab value="React">

```tsx
import { Avatar } from "@orbitdesign/ui/react";

<Avatar src="/me.jpg" name="Hammad Riaz" />
<Avatar name="Sara Khan" className="bg-primary text-primary-content" />
```

If there is no `src`, or the image fails to load, the avatar shows initials from `name`.

</Tab>
<Tab value="HTML">

```html
<span class="avatar"><img src="/me.jpg" alt="Hammad Riaz" /></span>
<span class="avatar bg-primary text-primary-content">SK</span>
```

</Tab>
</Tabs>

## Classes

| Class | Description |
| --- | --- |
| `avatar` | Base class |
| `avatar-xs` ... `avatar-xl` | Size |
| `avatar-square` | Rounded square |
| `avatar-group` | Overlapping stack |
