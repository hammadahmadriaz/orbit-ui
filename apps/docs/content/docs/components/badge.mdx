</Tab>
<Tab value="HTML">

```html

<span class="badge badge-error badge-dot badge-pulse">Recording</span>
```

</Tab>
</Tabs>

`pulse` sends a ring out from the badge, for things that are live right now. It stays still for users who prefer reduced motion. In holo mode, badges and their dots glow in their color.
